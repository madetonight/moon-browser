Moon beta — Apple silicon, macOS 26+

Quit Moon before replacing it. Install Moon.app in a writable Applications folder.
This Apple Development–signed beta is not Apple-notarized; macOS may require its
per-app first-launch approval. Follow Apple's instructions if you choose to trust
the download: https://support.apple.com/102445. No system protection is disabled.

Moon 0.3.0 or earlier needs this connected beta installed manually once. Later
published releases can use Settings → About → Check now. Background checks and
the automatic-install preference follow Moon's settings.

Updates require the dedicated Moon signing key, HTTPS, a signed feed and a signed
archive. No password, signing key or GitHub token is included in the app.
Profiles and browsing data remain on this Mac. Keep a backup before beta testing.
