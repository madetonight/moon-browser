# Moon 0.3.5 beta

Smoother sidebar hover, in both directions.

- Tab hover backgrounds now use a short 100 ms ease-in/ease-out on entry and exit, rather than fading in and disappearing immediately.
- Rapid crossings retarget the highlight while tab titles, close targets and selection stay immediate.
- Reduce Motion keeps hover changes instant.
- Native high-resolution icon compression reduces installed size to around 11 MB while keeping the approved Fluid Dusk artwork and small icon representations.
- Moon's current browser features remain included.

Apple silicon; macOS 26 or later. This beta is Apple Development signed and **not Apple-notarized**. Sparkle authenticates updates; it does not confer Gatekeeper trust.

Connected Moon builds can use Settings → About → Check now. Older builds with updates disabled need a one-time manual installation. Source and MIT attribution notices accompany this release.
